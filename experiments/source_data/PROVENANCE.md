# Original SocioPatterns workplace contacts: provenance and transformation

**Source:** SocioPatterns Collaboration, [Contacts in a workplace](https://sociopatterns.org/datasets/contacts-in-a-workplace/), released 23 June 2016. The file is the *InVS* office deployment (24 June–3 July 2013), **not** the 2015 second deployment. The source dataset is publicly dedicated under CC0. Cite Génois, Vestergaard, Fournet, Panisson, Bonmarin and Barrat, *Network Science* 3(3), 326–347 (2015), DOI **10.1017/nws.2015.10**.

**Archived original input:** `workplace_InVS_tij.dat.zip` (SHA-256 `bf818f7e819864e134c90ed82f2cda6ca9d9548d43fe4d05002ac068c91258c0`), containing `tij_InVS.dat`. Each record is `t i j`, meaning a measured face-to-face contact in the interval `[t-20s,t]`; anonymous participant labels only. The accompanying department metadata was not used, nor is it required to reproduce the analysis.

**Deterministic transformation:** Order the 92 participant labels numerically; count 9,827 20-second records; retain the union of 755 distinct undirected participant pairs over the entire observation window; add reciprocal off-diagonal transmission channels and one **assumed** local diagonal channel per node. The diagonal models an aggregate within-node contribution consistent with the submitted SEIR equations; it was **not recorded as an individual self-contact**. With `n=92` and `m=92+2*755=1602`, the first-closure dimension is `4n+2m=3572`. The original time stamps are used only to calculate aggregate counts and daily summaries. The SEIR simulation instead uses a *static* contact matrix.

**Two weight conventions:** (a) every supported channel (including diagonal) has base weight 1, then normalize each row to sum to 1; (b) off-diagonal weight is the observed pair's count of 20-second windows divided by the maximum pair count, each diagonal base weight is 1, and then normalize each row. The row normalization fixes incoming intensity and does not alter support. Neither rule estimates biological transmissibility.

**Matched networks:** 30 independent `G(92,755)` simple undirected graphs with NumPy `default_rng`/PCG64 seeds 20261112–20261141, with the same reciprocation, diagonal convention and row normalization. The model simulation uses `beta=0.8`, `sigma=0.25`, `gamma=0.1`, initial `E=I=0.001` at the smallest anonymous label and zero elsewhere, `T=60` model units, 401 samples, SciPy RK45 with the original numerical tolerances. All statistical summaries are descriptive, not confidence intervals for a population of workplaces.

**Limitations:** contacts measure proximity, *not infections*; individual participant IDs are used as indices for illustrative normalized SEIR model nodes; the data do not support disease calibration or observation-by-observation validation of SEIR infection trajectories. A single time-aggregated, fixed-weight support does not retain the original temporal ordering of contacts. No epidemiological policy or causal conclusion is drawn.

**Reproduction:** `python experiments/scripts/sociopatterns_workplace.py --repo . --out experiments/data --repeats 30`. Outputs: `workplace_topology.csv`, `workplace_residuals.csv`, `workplace_daily_contacts.csv`, `workplace_summary.json`. SHA-256 of raw archive is checked before parsing. No network access is necessary.
