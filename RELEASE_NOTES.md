# Release 1.0.3

Release `v1.0.3` is a documentation- and citation-metadata correction to
`v1.0.2`. It does not change the numerical model, experiment configuration,
random seeds, source code for the scientific computations, generated data,
LaTeX tables, PDF figures, or reported scientific results.

## Changes

- updated the release version to `v1.0.3`;
- updated the release date to `2026-08-24`;
- replaced obsolete repository links with
  `https://github.com/ebaeyens/repository-graph-induced-seir-lifting`;
- inserted the reserved Zenodo DOI `10.5281/zenodo.22080488` in the citation metadata and
  README;
- renamed `zenodo.json` to `.zenodo.json` to match the current Zenodo GitHub
  metadata convention;
- removed provisional text stating that a version-specific DOI was still
  pending;
- updated the release documentation and manuscript-alignment check for
  `v1.0.3`.

## Reproducibility

All scientific source files and all files under `output/` are unchanged from
`v1.0.2`. The release therefore reproduces exactly the same numerical evidence.
