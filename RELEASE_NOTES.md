# Release 1.0.0

This release reproduces the numerical results, tables, and figures used in the manuscript.

Key features:
- graph-induced quadratic and cubic dictionary metrics;
- unit-weight and fixed-incoming-transmission-intensity residual experiments;
- pre-specified admissibility criterion for the sparse random ensemble;
- recorded random seeds and realization-level outputs;
- peak-grid sensitivity check;
- reproducible three-subpopulation Algorithm 1 example;
- generated LaTeX tables and vector PDF artwork.
